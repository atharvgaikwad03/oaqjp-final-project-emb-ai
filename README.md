# Final Project

Repository for final project

This is the final project for the AI-Based Web Application Development course.

## Emotion Detection Application

This project implements an Emotion Detection web application using the Watson NLP library. The application detects emotions from text input and returns the dominant emotion along with scores for anger, disgust, fear, joy, and sadness.

## Project Structure

```
oaqjp-final-project-emb-ai/
├── EmotionDetection/
│   ├── __init__.py
│   └── emotion_detection.py
├── static/
│   └── mywebscript.js
├── templates/
│   └── index.html
├── server.py
├── test_emotion_detection.py
└── requirements.txt
```

## How to Run

```bash
python3 server.py
```

Then open your browser at `http://localhost:5000`

## Technologies Used

- Python
- Flask
- Watson NLP Library
- HTML/CSS/JavaScript
